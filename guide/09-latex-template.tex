\section{Todo notes (todonotes)}\label{app:latex:todo}

\missingfigure{A placeholder for a figure that does not exist yet.}
\beat{what a paragraph establishes}{its evidence}{what the running example shows in it}{the next paragraph}
\advisortodo{A note for the advisors: a draft to confirm or a link to add.}

\begin{runningexample}[a box]

\end{runningexample}

All notes are collected in the list of todos after the table of contents.
The submitted version is built from \texttt{reviewer.tex}, a four-line root file that sets the \texttt{final} class option, disables todonotes, defines \texttt{\textbackslash reviewermode}, and inputs \texttt{thesis.tex}: every note disappears, and \texttt{thesis.tex} skips the list of todos and the guide. On Overleaf, open \texttt{reviewer.tex} and choose \emph{Recompile from this file}; locally, \texttt{make reviewer}. Look at it every week, not only in the last one: it is the paper the reviewer gets.

\section{Abbreviations, notation and terms (glossaries-extra)}\label{app:latex:acro}
One file, \texttt{content/glossary.tex}, declares the three things a paper keeps lists of, and one command in each case uses them; the three tables are printed after the acknowledgements, only with the entries the text used, and every use links to its row.
\begin{itemize}[noitemsep]
  \item \textbf{Abbreviations.} The first use expands: \glsreset{vc}\gls{vc}. Later uses stay short: \gls{vc}. The plural: \glspl{vc}. One form on demand: \glsxtrshort{zkp}, \glsxtrlong{zkp}. Declared with \texttt{\textbackslash newabbreviation\{vc\}\{VC\}\{verifiable credential\}}.
  \item \textbf{Notation.} A symbol is declared once, with a description that points at the definition introducing it, and the table collects them: \gls{Rt} is the registry, and $\gls{valid}$ works inside math too. Typing \texttt{\$R\_t\$} directly is fine as well; the entry is what puts the symbol in the table, so declare every symbol of \cref{app:latex:theorems} and use \texttt{\textbackslash gls} at least where it is introduced.
  \item \textbf{Terms.} A word the paper uses in one fixed sense: an \gls{issuer} signs, a \gls{holder} presents, a \gls{verifier} checks. Use \texttt{\textbackslash gls} at the first use in a chapter, so the reader who forgot can click.
\end{itemize}
The template pins one workflow, \texttt{\textbackslash makenoidxglossaries}: the sorting is done by TeX, nothing else has to run, on Overleaf or locally. Give symbols a plain \texttt{sort} key. The internet will offer \texttt{makeglossaries} and \texttt{bib2gls} as well; neither is needed, and mixing them in breaks the build. The \href{https://ctan.org/pkg/glossaries-extra}{package documentation} is large; the \texttt{glossaries-extra} user manual's first chapter covers everything used here.

\section{Citations, links and icons (natbib, hyperref, bookmark, orcidlink, fontawesome5)}\label{app:latex:cite}
The bibliography is in IEEE style, \texttt{tdkieee.bst}: numbered in order of first citation, as the faculty's guideline asks for numbered references, with abbreviated first names and IEEE's punctuation. Numeric citations are sorted and compressed~\cite{w3c2025vcdm,lamport1978time}.
\texttt{\textbackslash citet} names the author: \citet{lamport1978time} introduced logical clocks.
\texttt{\textbackslash citep} brackets the reference~\citep{lamport1978time}.

Links: \url{https://github.com/ftsrg} prints the address, \href{https://ftsrg.mit.bme.hu}{the research group} hides it.
The PDF bookmarks in the viewer's sidebar come from hyperref and bookmark.
Icons: \faGithub~source code, \faFilePdf~paper, \faEnvelope~contact. Author ORCID: \orcidlink{0000-0000-0000-0000}.

\paragraph{Web pages.} The faculty's guideline, quoted in \texttt{include/guideline.tex}, says what an internet reference needs: \enquote{Internetes hivatkozások megadásakor fontos, hogy az elérési út előtt megadjuk az oldal tulajdonosát és tartalmát (mivel a link egy idő után akár elérhetetlenné is válhat), valamint az elérés időpontját.} So a web source is a \texttt{misc} entry whose author is the page's owner, in double braces so BibTeX keeps it whole (\texttt{author = \{\{W3C\}\}}), whose title says what the page is, with the \texttt{url} and the \texttt{urldate}, the day you read it. Zotero records the access date when you save a page and exports it as \texttt{urldate}; the template's bibliography style, \texttt{tdkieee.bst}, prints it after the URL as \enquote{Accessed: 2026-10-25}, which the stock styles would silently drop. The \texttt{w3c2025vcdm} entry in \texttt{bib/references.bib} is the pattern, and the \texttt{bib} lint rule flags a web source without an access date.

\paragraph{Where the entries come from: Zotero.} You do not write BibTeX by hand. Every source you read goes into the group library with the \href{https://www.zotero.org/download/connectors}{Zotero Connector} in your browser, one click on the paper's page or its DOI; Zotero fetches the metadata, and you fix what it got wrong there, once, for everyone. Overleaf's Zotero integration turns the group library into \texttt{bib/zotero.bib} (\cref{app:start:access}); \emph{Refresh} on that file pulls in what was added since. The citation key is the one Zotero generates, visible in Overleaf's autocomplete after you type \texttt{\textbackslash cite\{}. Official guides: the \href{https://www.zotero.org/support/quick_start_guide}{Zotero quick start guide}, \href{https://www.zotero.org/support/groups}{group libraries}, and Overleaf's \href{https://www.overleaf.com/learn/how-to/How_to_link_your_Overleaf_account_to_Mendeley_and_Zotero}{linking your account to Zotero}. Working locally, the \href{https://retorque.re/zotero-better-bibtex/}{Better BibTeX} plugin keeps an auto-exported \texttt{.bib} in sync with the library and gives stable citation keys. Three habits keep the bibliography clean: check the entry type and the title's capitalisation when you save (protect names and acronyms with braces, \texttt{\{BPMN\}}), add the DOI where one exists, and put hand-written entries that are not literature, the Zenodo artifact and AI citations, in \texttt{bib/references.bib}, because a refresh overwrites \texttt{zotero.bib}.

\section{Mathematics and theorems (amsmath, unicode-math, ntheorem)}\label{app:latex:theorems}
A numbered equation:
\begin{equation}\label{eq:latex:window}
  \mathit{valid}(c, t) \iff t \in [t_\mathrm{issue}(c), t_\mathrm{exp}(c)) \land c \notin R_t .
\end{equation}
Aligned equations, each with its own number:
\begin{align}
  R_{t+1} &= R_t \cup \{ c \} \label{eq:latex:fresh}\\
  \mathit{valid}(c, t+1) &\implies \mathit{valid}(c, t) \label{eq:latex:valid}
\end{align}
Symbols beyond amsmath come from the math font: $\mathbb{N}$, $\mathcal{R}$, $\nexists$, $\varnothing$.

Every theorem-like environment, in a typical order.
Definitions and examples have their own counters; the rest share the theorem counter.
\begin{definition}[Revocation registry]\label{def:latex:registry}
A \emph{revocation registry} is a set $R_t$ of revoked credential identifiers at time $t \in \mathbb{N}$.
\end{definition}
\begin{notation}\label{not:latex:issuer}
$I(c)$ denotes the issuer of credential $c$.
\end{notation}
\begin{example}\label{ex:latex:registry}
A university revokes a diploma credential $c$ at $t=5$, so $c \in R_5$.
\end{example}
\begin{invariant}\label{inv:latex:monotone}
The registry only grows: $R_t \subseteq R_{t+1}$ for every $t$.
\end{invariant}
\begin{property}[Revocation is final]\label{prty:latex:final}
If $c \in R_t$, then $\mathit{valid}(c, t')$ is false for every $t' \geq t$.
\end{property}
\begin{lemma}\label{lem:latex:step}
If $\mathit{valid}(c, t+1)$, then $\mathit{valid}(c, t)$, by \cref{eq:latex:valid}.
\end{lemma}
\begin{proof}
By \cref{inv:latex:monotone}, $c \notin R_{t+1}$ implies $c \notin R_t$.
\end{proof}
\begin{theorem}[Finality]\label{thm:latex:finality}
\Cref{prty:latex:final} holds for every registry that satisfies \cref{inv:latex:monotone}.
\end{theorem}
\begin{proof}
Induction on $t' - t$ with \cref{lem:latex:step}.
\end{proof}
\begin{corollary}\label{cor:latex:noresurrect}
A revoked credential is never valid again.
\end{corollary}
\begin{proposition}\label{prop:latex:size}
After $n$ revocations, $|R_t| = n$.
\end{proposition}
\begin{claim}\label{claim:latex:append}
An append-only log implements $R_t$.
\end{claim}
\begin{remark}\label{rem:latex:expiry}
Expiry is not revocation: an expired credential is not in $R_t$.
\end{remark}
References: \cref{def:latex:registry}, \cref{not:latex:issuer}, \cref{ex:latex:registry}, \cref{inv:latex:monotone}, \cref{prty:latex:final}, \cref{lem:latex:step}, \cref{thm:latex:finality}, \cref{cor:latex:noresurrect}, \cref{prop:latex:size}, \cref{claim:latex:append}, \cref{rem:latex:expiry}.

\section{Tagged lists and other lists (enumitem)}\label{app:latex:tags}

  \item\label{c:latex:model} A formal model of revocation registries.
  \item\label{c:latex:impl} An implementation on a permissioned ledger.
\end{contributions}
\begin{rqlist}
  \item\label{rq:latex:latency} How long does a revocation take to become visible?
\end{rqlist}
\begin{requirements}
  \item\label{req:latex:offline} Verifiers can check revocation status offline.
\end{requirements}
\begin{threats}
  \item\label{thr:latex:replay} A holder replays a credential after its revocation.
\end{threats}
\begin{assumptions}
  \item\label{asm:latex:clock} Participants' clocks drift by at most $\delta$.
\end{assumptions}
\begin{guarantees}
  \item\label{g:latex:detect} Under \cref{asm:latex:clock}, every replay in \cref{thr:latex:replay} is rejected within $\delta$.
\end{guarantees}
\begin{limitations}
  \item\label{lim:latex:liveness} The registry cannot force an issuer to revoke.
\end{limitations}
References: \cref{c:latex:model,c:latex:impl}, \cref{rq:latex:latency}, \cref{req:latex:offline}, \cref{thr:latex:replay}, \cref{asm:latex:clock}, \cref{g:latex:detect}, \cref{lim:latex:liveness}.

\section{Algorithms (algorithm, algpseudocode)}\label{app:latex:alg}
\begin{algorithm}[!ht]
  \caption{Revocation with a freshness check}\label{alg:latex:revoke}
  \begin{algorithmic}[1]
    \Require credential $c$, registry $R$, time $t$
    \If{$c \in R$}
      \State \Return \textsc{already-revoked}
    \EndIf
    \State $R \gets R \cup \{c\}$ \Comment{\cref{eq:latex:fresh}}
    \State \Return \textsc{ok}
  \end{algorithmic}
\end{algorithm}

\paragraph{Refinery, Tamarin and Lean (listings).}
\Cref{lst:latex:refinery,lst:latex:tamarin,lst:latex:lean} use the listings styles \texttt{refinery}, \texttt{tamarin} and \texttt{lean}.
\begin{lstlisting}[style=refinery, float=tbp, morekeywords={[2]Credential,Issuer,Holder}, caption={Refinery: a credential metamodel with an error predicate.}, label={lst:latex:refinery}]
class Issuer.
class Holder.
class Credential {
    Issuer[1] issuedBy
    Holder[1] heldBy
    contains Credential[0..1] revokes
}

pred selfRevoked(Credential c) <->
    revokes(c, c).

error unissued(Credential c) <->
    !issuedBy(c, _).
\end{lstlisting}

\begin{lstlisting}[style=tamarin, float=tbp, caption={Tamarin: revocation as a multiset-rewriting rule and a lemma.}, label={lst:latex:tamarin}]
theory Revocation
begin
builtins: signing

rule Revoke:
    [ !Issued($I, cred), Fr(~nonce) ]
  --[ Revoked(cred) ]->
    [ !RevokedFact(cred), Out(sign(<cred, ~nonce>, ~sk)) ]

lemma revoked_never_accepted:
  "All cred #i #j. Revoked(cred) @ i & Accepted(cred) @ j ==> j < i"
end
\end{lstlisting}

\begin{lstlisting}[style=lean, float=tbp, caption={Lean 4: the registry only grows (\cref{inv:latex:monotone}).}, label={lst:latex:lean}]
-- A registry is a list of revoked credential identifiers.
def Registry := List Nat

def revoke (r : Registry) (c : Nat) : Registry := c :: r

theorem revoke_monotone (r : Registry) (c x : Nat) :
    x ∈ r → x ∈ revoke r c := by
  intro h
  exact List.mem_cons_of_mem c h
\end{lstlisting}

\section{Text (csquotes, ulem, xcolor, xspace, babel, setspace, lineno, comment)}\label{app:latex:text}
Quotes adapt to the language: \enquote{revocation is final}, and nested: \enquote{the issuer said \enquote{revoked}}.
ulem marks edits: \uline{underlined}, \sout{struck out}, \uwave{wavy}. xcolor colors text: \textcolor{red!70!black}{red}, \colorbox{yellow!40}{highlighted}.
Abbreviation macros use xspace, so they need no trailing braces: \eg the issuer, \ie the registry, Lamport \etal showed.
babel switches the hyphenation and quotes per phrase: \foreignlanguage{magyar}{\enquote{visszavont tanúsítvány}}.

\begin{onehalfspace}
setspace changes the line spacing for a block; this paragraph uses one-and-a-half spacing.
The rest of the thesis is single-spaced, as the TDK rules require.
\end{onehalfspace}

\begin{linenumbers}
lineno numbers lines, so reviewers can point at them.
Wrap a draft paragraph in a \texttt{linenumbers} environment, or put \texttt{\textbackslash linenumbers} in the preamble for the whole document.
\end{linenumbers}

The comment package hides a block without deleting it. The next paragraph is inside a \texttt{comment} environment and does not appear.

This sentence is in the source but not in the PDF.
\end{comment}
